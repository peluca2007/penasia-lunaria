# Cronologia anterior — arquivo

Esta versão pertence ao rascunho em que Anaviosi precedia Lunária. Guarde apenas como referência histórica.

### Cronologia <span class="st proposta">proposta</span>

Só a ordem das eras e os cerca de 20.000 anos são <span class="st fechado">fechado</span>. As datas exatas são proposta. Lunária conta os anos a partir da Queda da Lua (ano 0).

**Antes de Lunária**

| Quando | Evento |
|:--|:--|
| sem data | **Pena**, o mundo antigo: as Bruxas e os Cavaleiros do Apocalipse. |
| sem data | **O Reset.** A Morte mata todas as Bruxas, consome a autoridade delas e reinicia o mundo. |
| −21.000 | **Anaviosi.** A Morte e outro cavaleiro criam o mundo novo e morrem. Genbu traz a tecnologia de Pena. |
| −21.000 a −19.000 | O auge do Anaviosi: cidades de máquina, os Monges, a longevidade. |
| −19.000 | Genbu morre. As máquinas param, uma cidade por vez. |
| −19.000 a −9.000 | **A Ferrugem.** Dez mil anos de ruína. A técnica vira relíquia; a relíquia vira mito. |

**O que os templos de Lunária contam** (o mito começa aqui; antes disso, para eles, só havia o Vazio)

| Ano | Evento |
|:--|:--|
| −9.000 | Ausa empresta a existência: nasce Lume, e a sombra dele é Torvo. |
| −8.000 | Os espíritos criam os Inteiros, a primeira raça. |
| −6.000 | As Anomalias: nascem elfos, humanos, anões, gnomos e miúdos. |
| −4.000 | Torvo parte um único desejo em dois: Carmina nasce, Fauce dorme no ventre da terra. Lume cria Rubra. |
| −3.990 a −3.800 | Nascem Cisma; Fauce acorda; surgem a morte, o luto, Modorra e o sono. |
| −3.000 | Usura: os primeiros reinos. |
| −60 | Lume e Torvo criam Altiva. Artur funda o primeiro reino. |
| −11 a 0 | Guerra de Artur contra Altiva. A lua se parte. |
| **0** | **A Queda da Lua.** Metade cai sobre a capital de Artur. Altiva dorme no Fragmento. Começa a contagem dos anos. |

**Depois da Queda**

| Ano | Evento |
|:--|:--|
| 72 | Fauce forja os Elfos Lunares no vácuo da Meia-Lua. |
| ~400 | Caliburna troca súditos por exército com Fauce: os Titânicos. |
| ~780 | Rebelião de Zane; exílio dos Elfos das Cinzas. |
| ~985 | O goblin DROP funda a Fundação Punho Aberto. |
| 1000 | Fauce massacra 200.000 Titânicos. |
| 1017 | Galdor, DROP e amigos matam Fauce. A Meia-Lua cai nas mãos dos Devoradores. O Ossário começa a sumir. |
| 1019 | Altiva acorda. |
| 1020 | Hoje. |
