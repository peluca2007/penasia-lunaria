# Diretriz nova do autor (vale para todos os agentes)

1. **Variedade enorme de builds.** No sistema antigo, dois personagens da MESMA classe saíam muito diferentes, porque havia centenas de opções somadas: características/talentos, treinos, magias extras, multiclasse, interclasse, raças, Dádivas. O autor quer manter essa sensação: muitas escolhas pequenas e combináveis, não só "classe + subclasse".
2. **Multiclasse deve dar coisas** (talento extra, magia extra, sinergias), como antes.
3. **Precisa ter MAGO.** Um conjurador arcano de verdade, com magias que se aprendem e se colecionam. O "Destilador" do rascunho de classes não substitui o Mago. O autor também espera ver os arquétipos clássicos representados (o livro antigo tinha as 12 classes de D&D + Voidwalker + Avatar), com nomes e mecânicas próprios.
4. Continua valendo: classes não dependem de pecado/Credor; combate tático é a vitrine; nada de descartar o livro antigo à toa.

Implicação para o design: a ficha precisa de **camadas de personalização** (ex.: Classe → Subclasse → Técnicas escolhidas de uma lista maior → Talentos/Características → Treinos → Magias → Origem/Heranças → Pacto opcional), mas o turno de combate continua rápido de jogar.
